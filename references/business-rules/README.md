# 原业务规则保留库

2026-10-28 将原31个角色技能移入本目录，原 `SKILL.md` 仅改名为 `RULES.md`，文本字节未改动；原UI元数据和相关附属文件一并保留。它们是当前能力入口加载的业务规则，不是31个独立子 Agent，也不是另一套自动发现的活跃技能。

当前组织和任务负责人以 [任务路由](../../catalog/task-routing.json) 为准，[角色注册表](../../catalog/agent-registry.json) 的 `legacy_aliases` 保存全部旧名称去向，便于解释原文中的交接名称。[角色索引](../../catalog/AGENT-INDEX.md)提供可读对照。

- `.agents/skills/` 中的新入口按当前任务选择本库的规则模块；进入模块后完整读取，并继续读取原文要求的来源业务规则。
- 原文中的步骤、数值、公式、适用范围、前置条件、必需交互和免责声明继续保留。规则预估与实际观测分别记录，不因组织合并而删除预估规则。
- 原文中的旧角色交接按别名映射处理。同一当前负责人内切换能力模块，不重复创建相同角色。路由改名不改变业务阶段和核验要求。
- 原宿主的组件、命令和连接差异记录为适配问题；不冒充当前宿主已有能力，不用摘要覆盖或静默停用原业务条款。
- 原文和历史元数据中的日期、角色数、旧提示词用于保留迁移前事实，不作为当前组织配置。新的可调用技能、UI元数据和子 Agent 配置位于活跃入口中。

完整性依据见[保留清单](../../manifests/routing-refactor-20261028-preservation.json)。校验脚本逐项核对原路径、保留路径及 SHA-256；本库63个规则及附属文件与2658个来源、图片资产和既有报告文件均有保留记录。修改本说明不应修改清单中已固定的原始内容。

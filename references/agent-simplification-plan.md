# Agent 精简设计方案（讨论稿）

更新日期：2026-10-30（Asia/Shanghai）。本次先记录用户确认补入的“当前任务”定义与“商品链接完整运营闭环”，其他精简设计后续继续讨论。本文是方案草案，尚未改动运行入口、任务路由或规则加载要求。

设计依据：[销售增长运营流程](sales-growth-workflow.md)与[本店阶段策略](account-strategies/songtai-sales-growth.md)。根目录已作为唯一总控入口；核心目标沿用销售额提升、新品推广及商品链接流量与转化改善，产品价格固定。

## “当前任务”的定义

当前任务是总控本轮准备处理的一项具体工作，来源可以是用户直接要求、经营数据发现的问题、公司指定新品或重点产品，以及已经到期的措施评估或人工完成回执。

任务应明确处理对象、要解决的问题或目标、现有证据、当前阶段和预期交付。例如：查明某条链接曝光下降的原因、为新品制定推广方案、优化采购信息表达，或评估上次调整后的效果。

标题、主图、详情是可选择的具体措施。总控应先判断哪个运营环节需要处理，再确定具体工作及负责人；不能把“提升链接销售额”默认转成修改标题、图片和详情。用户已经明确指定的小任务直接按范围处理，无须补做全店诊断。

## 商品链接的完整运营闭环

| 运营环节 | 要解决的问题 | 可能形成的具体任务 | 主要分工 |
|---|---|---|---|
| 产品定位与需求匹配 | 产品卖给谁、满足什么采购需求，与已有链接有何区别 | 明确采购客群、用途、核心卖点，核对类目、属性、规格组织及新品定位 | 商品运营；总控确认公司目标和优先级 |
| 获取流量 | 曝光不足、点击不足，或来客不匹配 | 分析搜索词和流量渠道，制定自然流量或付费推广方案；按证据优化标题、主图表达及推广关键词、人群、素材 | 流量运营负责流量诊断与推广；商品表达调整由总控交商品运营 |
| 访问后的承接 | 客户看过后为什么不询盘或不直接下单 | 检查详情、图片或视频、规格说明、采购单位、起订条件、交期、资质及供货信息是否准确完整，形成具体改进方案 | 商品运营；来客匹配问题由流量运营协作 |
| 询盘到成交 | 有询盘但订单不足，或样单未推进至大货 | 分析询盘质量、响应、需求确认、现行报价使用是否准确、寄样及跟进，提出相应改进任务 | 总控按触发条件调用 conversion_analysis；销售执行或公司决定明确交接 |
| 成交规模与持续销售 | 转化没有明显下降，销售额仍然偏低 | 检查采购数量、订单均额、商品与客群结构、大单节奏、供货履约及复购情况，识别实际影响环节 | 总控统筹，按证据调用商品、流量或相关专项；供货与商业事实由公司核实 |
| 措施效果 | 上次调整是否有效，是否继续 | 对照行动前固定基线、实际结果及同期干扰因素，形成保持、扩大、调整、停止或补证的决定 | 原负责领域提供评估，总控验收并更新行动状态；必要时独立复核 |

上述环节共同构成链接运营范围。实际任务只下钻有必要、有依据的环节；证据不足时明确补证项，指标正常时可以保持现状。不能预设每条链接都要修改所有内容，也不能保证某项优化必然提升成交。

## 总控如何据此选择任务与加载规则

调度顺序为：明确目标和对象 → 检查相关既有行动 → 根据数据或公司要求定位待处理环节 → 形成具体任务 → 交对应执行者 → 核验执行并评估效果。

“按当前任务加载”的设计，应依据“运营环节＋任务阶段”选择所需信息。任务阶段包括诊断、制定方案、执行、生效核验及效果评估；任务清单必须覆盖上述完整闭环，不能只用标题、主图、详情几类编辑动作代表全部链接运营。

例如：

- “分析 A 链接流量下降”先进入流量诊断；只有证据支持商品表达问题时，才产生标题或素材任务。
- “改善 B 链接询盘成交”先核对询盘质量与可关联、已成熟的成交链路；结果可能是改进需求确认或跟进，而不是修改页面。
- “推广公司指定新品”先核实定位和真实供货条件，再准备商品承接与推广方案；无历史成交不直接判失败。
- “更换已确认的主图”按具体对象、素材、授权及已有观察状态执行，不扩大为全店经营诊断。

具体负责人和能力继续对照[现行任务路由](../catalog/task-routing.json)。未来精简规则加载时，需要同步调整相关入口与技能的读取要求；本次仅补充方案定义，不据此跳过现行适用规则及其前置条件。

## 事实、授权与人工参与

后台数据用于观察流量、渠道、询盘、订单和成交等表现；公司资料用于确认产品用途、真实规格、既定价格、起订条件、交期和供货能力。缺少事实写明待核实，不能用推测补齐。

产品价格固定，不通过改标价、阶梯价、报价规则、折扣或优惠券来优化转化。规格、起订量、交期等真实商业条件只能核实和准确表达，不能擅自改变。利润分析不作为当前推进前置。

标题、主图、详情沿用已有人工审核要求及具体授权；销售触达、投流和其他实际操作按现有授权与能力执行。工具不支持的字段或动作交付具体人工方案。分析建议不计为已执行，人工方案交付不计为已生效。

实际生效确认后才开始措施观察；后台字段回读与买家页面展示核查分别记录。单次行动观察与公司重点产品长期跟踪保持独立。比较周期、数据口径、观察条件及记录字段统一引用销售增长运营流程，避免在方案中另建一套标准。

# 曝光、询盘与新客成交分析口径

生效：2026-11-08，Asia/Shanghai。适用于本项目当前店铺的经营及投放分析，依据[有效策略](account-strategies/songtai-sales-growth.md)。整体成交额继续作为经营结果，新客、老客、身份未知的成交额明确拆分；投放拉新效果另行评价。本文件集中定义口径，取数步骤、实时接口能力及原始证据仍按各领域规则核实。

## 两类分析任务

| 任务 | 诊断顺序与交付 |
|---|---|
| 账号整体分析 | 同时看全店及已确认核心商品的曝光 → 点击量与点击率 → 新客有效询盘 → 成熟询盘到首单的转化。指出变化主要来自哪些商品、渠道和环节；整体成交额及新/老/未知拆分明确展示。 |
| 投放商品分析 | 按统计期消耗范围检查商品的上述漏斗，重点判断新增有效采购机会、新成交客户、首单及新客队列成交额和获客成本。有归因成交先核客户身份与获客来源；平台总体产出比保留作对账和辅助解释。 |

核心商品使用公司明确清单或已有有效 `focus_id`；未明确时可提出有依据的候选并注明，不能把花费排名直接当公司核心清单。分析按上述顺序组织，不要求前一环节完全确诊后才处理已知的下游异常。

曝光和点击是否足够，结合可比历史、同类商品/渠道、采购场景、样本及观察期判断，不编造全店统一阈值。曝光足而点击弱时核搜索意图、流量构成与真实标题/主图；点击足而询盘弱时核需求匹配、详情及规格/采购信息、接待承接；成熟询盘转化弱时核报价、寄样、跟进与采购节点。指标组合只提供候选原因，不能自动归因到主图或价格。价格固定。

## 客户身份与成交来源

这里的公司新客指对本公司的新成交客户，不是平台的企业买家类型。身份依据来自可关联的站内订单、公司历史合作/交易记录及CRM证据；记录覆盖期间、判定时点和来源。平台首购、CRM新增日期、`source=INQUIRY` 或空订单日期，均不能单独证明公司新客；已有CRM记录但从未成交的线索也不能自动算老客。

**成交额拆分默认固定统计期队列。** 期初之前已与本公司成交的买家属于老客；有足够历史覆盖证实期前未成交、且本期首次成交的买家属于本期新成交客户；覆盖或关联不足者为身份未知。新客队列成交额包括该买家本期首单及后续订单，首单人数/金额另列，不在同一期因其第二笔订单来回切换身份。其他业务口径可以使用，但须声明定义与版本，不能混算。全店与广告报表分别在自身相同金额口径内拆分，合计应与各自原总额对平；未覆盖部分进入未知或未关联，不凭比例分摊。

**询盘阶段独立识别新客候选。** 按该询盘发生前的本公司成交历史判断，历史覆盖充分且无既往成交者可进入新客有效询盘队列；未知单列。不能等后来成交后才挑选新客询盘，否则会高估询盘转化率。客户后来成交时更新其阶段与证据，保留原队列及判定时点。

客户身份与获客来源是两个维度：

- 平台归因成交原值照录，并保存平台窗口、退款和归因定义；平台归因不等于真实增量。
- 核对可取得的首次获客来源、广告关联证据以及已知业务引导下单记录。老客由业务人员引导在平台下单，仍为老客；平台即使归因给广告，也不计入广告拉新成绩。不把所有老客订单未经核实都写成业务引导。
- 公司新客出现在广告报表中，不自动证明广告首次获客；关联不足则写“新客成交已确认、广告获客来源未确认”。仅有商品聚合成交额时，不能反推具体买家、订单或新客比例。
- 报告给出身份核验覆盖和仍未知的金额/人数。已有授权范围内先查可取得证据，仅将真正影响决定且无法补齐的事项交用户；身份缺口不阻塞独立可做的曝光、点击和商品表达分析。

## 指标与队列

| 指标 | 使用口径 |
|---|---|
| 曝光、点击、点击率 | 同渠道/位置/期间的点击÷曝光；注明点击次数或点击人数，不混用不同统计口径。整体和核心商品同时观察，不能用泛商品曝光增长掩盖核心商品下降。 |
| 访问到有效询盘 | 优先用同口径的去重有效询盘买家÷去重访客；新客专属询盘率还需匹配的新客访客分母。只有总访客时可报告“新客有效询盘人数/总访客”，须保留该名称，不能称新客访客转化率。点击次数不能直接冒充访客人数。 |
| 有效询盘 | 根据真实采购需求、商品适配及询问内容等可核实事实判定；无效、有效性待核分别保留。平台询盘、平台优质询盘和线索保留原口径，未核实不能改称有效新客询盘；跨商品/渠道重叠买家按可用关联去重。 |
| 询盘到首单 | 同一新客有效询盘队列中，在约定成熟窗口内已首单成交的去重客户÷该队列中达到相同成熟条件的客户。说明队列发生期、观察截止、采购阶段与退款回补；未成熟者单列，不用本期全部订单÷本期全部询盘。 |
| 直接下单 | 无询盘直接成交的新客单列，纳入真实成交及新客结果，不硬塞进询盘转化率。样单和大货分别描述。 |
| 获客成本及产出比 | 广告费用与新客人数/成交额必须具有一致范围；身份和来源覆盖不足时不给确定性排名。若展示暂定值，明确其仅依据已确认部分及覆盖限制。平台归因成交额÷花费仍称平台广告产出比，另列确认新客的结果，不作为利润结论。 |

各比例从可比原始分子分母重算；缺失不填零，零分母不定义，期间去重买家不跨日相加。身份或有效询盘口径变化时记录定义版本和证据，保留旧固定基线，不静默重写历史。复用现有转化队列/问题状态，只保存必要聚合与证据引用，不建立第二套客户主档。

## 消耗覆盖与报告

投放分析须交代统计期内有消耗的商品范围及总额，兼顾昨日异常和累计消耗。正文可以只展开优先对象，但附录/数据文件须覆盖其余对象，并给出已分析花费、未展开花费及占比；不能把“昨日有消耗”当成整个期间的商品集合。大额成交集中时补充剔除该对象后的盘面，并先核新老客及来源，不能用单个大单证明全体商品投放良好。

正文以简短的效果、原因依据、经营选择和实际待审成品为主；整体成交额与新/老/未知拆分必须可见。数据限制只保留会改变判断的部分，完整口径、过程记录、全量明细和原始证据放附录，使用交付环境可访问的路径。补查写明不同结果将怎样改变选择；证据支持商品修改时按[成品审核与应用](sales-growth-workflow.md#成品审核与应用)继续制作，不把“建议改图/改标题”当作该项完成。

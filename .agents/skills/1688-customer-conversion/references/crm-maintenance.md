# 客户导入、标签与属性维护

维护属于数据写入，先读[客户管理完整规则](../../../../references/business-rules/1688-crm-manager/RULES.md)和[执行协议](../../../../references/execution-protocol.md)。用户只要求查询、分层或建议时不自动导入、打标、改属性。已有明确写入授权继续有效；缺少目标/字段/覆盖决定时先准备具体差异，再询问尚缺内容。所有工具先 live describe，网关负责店铺身份，不提交内部认证字段。

| 需求 | 候选工具 | 执行前必须明确 |
|---|---|---|
| 导入/新增客户 | `customer_import` | 客户来源、匹配线索、字段映射、目标店铺和覆盖范围；已存在记录会合并 `extra_attrs`，新值覆盖旧值 |
| 给指定客户打标 | `customer_tag_batch_apply` | 确定的客户 ID 或经核验筛选条件、非空标签；不存在的标签可能自动创建 |
| 新增字段 | `customer_attr_add_column` | 字段显示名、类型与初始值；先查已有定义避免重名/重复字段，不猜 `attrKey` |
| 查看字段和标签 | `customer_attr_field_config` / `customer_attr_list_all` | 只读查询不自动变更定义 |

已核验 Schema 的业务参数示意：

```json
{"loginIds":["本次查询取得的完整客户标识"],"tags":["用户明确要求的标签"]}
```

```json
{"attrLabel":"用户要求的字段显示名","attrType":"string","value":"用户明确指定的初始值"}
```

```json
{"items":[{"basicInfo":{"customerName":"用户提供的客户名称","customFields":{"已核验字段键":"用户提供的值"}},"identifierClues":{"wangwangId":"用户提供且已核对的旺旺标识"}}]}
```

以上仅说明键名和类型，不是可直接运行的业务数据。`customer_import` 的线索、`initialPortrait`、`wikiParsedBehavior` 只填用户提供或已验证事实，不补造手机号、意愿、交易或画像。新增属性的快照描述与暴露字段存在不一致，不能擅加 `attrKey/loginIds` 等未暴露参数或声称能批量填指定客户；以 live 契约和回读为准。

同一对象串行，记录字段差异、真实回执及回读。失败或未知结果先查实际客户/标签/字段状态，不盲目重复导入或建列。交付新增、合并、失败和未知数量以及差异摘要，最多 20 条脱敏示例，不复制完整客户库；站内手机号隐藏、地区限制和包装标识规则沿用[客户查询](crm-query.md)。商家打上的“高意向”标签不会因此变成平台采购意愿评分。

“接聚水潭/吉客云/销帮帮”“同步 ERP 客户”“企业微信连接”走项目[任务路由](../../../../catalog/task-routing.json)中对应连接或 ERP 能力，核对真实连接状态与独立授权。前端显示可连接、CRM 导入成功都不证明 ERP 已接通；不通过本文件私读凭证、建立连接、全量同步、合并同人或删除来源数据。当前工具不支持的删除标签/字段或配置变更，说明缺口，不改用前端私有 API。

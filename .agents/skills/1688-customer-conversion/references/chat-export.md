# 询盘聊天查询与导出

用于用户指定店铺、日期或买家的询盘聊天记录查询及文件交付，路由为 `chat_export`。它不等于客户库导出，也不自动启动客户画像、转化深析或客户触达。先复用上下文已明确的店铺、日期和输出范围；确实缺少会影响取数的范围时再询问。

## 工具与范围

先按[连接和工具](../../../../references/runtime.md#连接和工具)核对当前连接与 `tool_context`。下表是当前候选的参数要点，来源为[当前工具定义](../../../../catalog/current-tool-definitions.json)；实际调用前仍读取实时 `describe_tool`，以该工具最新定义为准，不把历史成功或本地索引当永久权限。

| 工具 | 用途与已知参数 |
|---|---|
| `inquiry_data_batch_query` | 文档优先的分批入口。`ds` 必填，字符串 `YYYYMMDD`。首批可选非空 `buyer_loginId` 查询指定买家；未指定买家的全量分页首批可选 `pageSize`，为 `1`—`50` 的纯数字字符串，默认 `50`。续查使用原样返回的 `cursor`，不再带 `pageSize` 或非空 `buyer_loginId`，保持同一商家与 `ds`。 |
| `inquiry_data_query` | 按 `ds` 或 `ds` 加 `buyer_loginId` 查询。当前 Schema 未提供页码或游标，不能自造分页参数，也不能凭“所有/完整”描述忽略实际截断或缺口。 |
| `inquiry_data_load` | 按 `ds` 与真实买家索引 `idx` 读取当日对话。`idx` 为从 `1` 开始的整数字符串，省略默认 `1`；按返回的索引和范围调用，不能猜造买家序号或拿买家 ID 代替。 |

店铺身份由网关注入；只有网关发出的 `store_ref` 可以选择授权。不要自行填写商家登录 ID 或其他内部路由字段。日期按用户时区解析，多日请求逐日处理并保留每天状态；指定日期不能暗换为最近滚动窗口。买家登录 ID 保留真实返回值及原有占位格式，不从昵称猜造。

这些工具的查询说明与通用效果标签可能不同，按实时说明、参数和本轮动作判断。遇到权限拒绝，先保留错误码及被拒范围，区分批量方式受限、对象受限和整体访问受限。拒绝范围未明确前暂停受影响查询，不自动改用逐条接口或拆批；只有拒绝说明、实时定义或有效权限证据明确允许的独立范围才可继续。某一接口拒绝不代表所有聊天接口都没有能力；某一天或某个买家成功也不证明其他范围可访问。

## 分批与完整性

- 分批响应 `data.hasMore=true` 时，按真实 `data.nextCursor` 续查；游标可能继续长正文分段，而不只是下一位买家。游标原样传递，不构造、不修改、不传空字符串或 `null`。
- 返回条数少于 `pageSize` 不代表结束。以终止标记及错误信息核对完成；缺失/重复游标、连续无进展或分段异常时停止该链并保留未完成范围，不无限重试，也不把它算作零记录。
- 保存每次请求范围、工具、日期、分页/分段顺序、原始回包引用及成功/空结果/失败/拒绝状态。成功返回的所有批次都纳入交付，不能只导出最后一批；失败范围单列，不能静默遗漏某天或某买家。
- 按真实消息 ID、会话和分段标识恢复顺序与完整正文；没有稳定 ID 时保留来源位置并说明去重限制。不能只按相同文字去重，避免删除真实重复发言；长文分段未拼齐时标记缺段。
- 可取得总数、已返回买家/会话/消息数及截止信息时相互核对；这些计数口径不同，不能混称。没有可信总数或结束证据时交付“已取得范围”，不要声称全店或整段期间完整。

## 文件保真与验收

保留原始回执用于复核，另生成用户需要的可读文件。每条记录应能回到日期、买家/会话、消息及原始来源；保留实际返回的发送方、时间、消息类型、完整正文、图片/文件等附件引用。字段未返回记缺失，不从概览或 AI 摘要还原原话；摘要与原文分开。保留原始时间并说明展示时区。

附件按实际返回情况记录类型、名称、URL 或资源 ID；只有真正取得文件时才写本地文件位置。只拿到附件链接不能声称已导出附件内容，无法访问或已过期的资源明确标记。导出聊天不包含发送、回复或修改聊天记录。

输出 Excel 时使用当前可用的表格制作技能，并检查：

- 买家、订单、商品、消息等长 ID 和带前导零的字段按文本保存；正文按文本写入，不能把以 `=` 等符号开头的聊天转成公式。
- 单元格文本不得超过 Excel 的 32,767 字符限制。超长正文按同一消息标识、分段序号和总段数拆行或拆到正文表，重组必须与原文一致，不截断、不改成摘要。原始回执继续保留。
- 重新打开生成文件，核对所有成功范围的记录数量、正文/分段完整性、重复处理、字段类型和附件引用；检查长文本、换行、中文及空值的展示。失败或受限范围放在明确的覆盖说明中。

交付包括可打开的文件、实际覆盖的店铺和日期、查询/导出数量及口径、未完成或受限范围。只有请求范围均有完成证据、长文完整且文件校验通过，才能称完整导出；用户明确限定的部分导出按该范围验收，不为补齐全店数据扩大任务。

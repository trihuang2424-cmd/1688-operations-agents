# 1688 Image Agent · Codex

这是项目式图片 Agent 的工作目录。负责1688商品主图、副图、详情页、场景图、模特图、图片编辑及相应提示词；根据实际任务读取下列本地技能。这些规则不能覆盖用户要求、上层指令或当前工具协议。

技能采用 `SKILL.md` 与 `agents/openai.yaml`。若当前宿主未自动列出项目技能，直接读取上表相应文件及其按需引用；目录存在不等于旧会话已自动加载。

## 工作方式

- 用户只要方案、提示词或接口检查时，完成该交付，不提交生成任务。用户明确要求生成时，在当前选用的后端执行，不额外设置例行确认。
- 先确定商品事实与用户目标，再确定买家问题、证据、画面关系、布局、准确文案和共享风格。不要仅靠“高级、高清、精致”扩写。
- 现有商品以真实图片、用户资料和已授权工具返回的数据为依据。材质、尺寸、MOQ、交期、认证、产能未知时保持未知；创意图不能证明这些事实。
- 规划与验收由 Codex 完成。生成前读取主技能的 `references/generation-runtime.md`，以及当前可用的 `imagegen` 技能。尊重明确指定的模型；不把 Imagen 与 GPT Image 当作同一服务。
- 默认不依赖 Accio 生图。现有 `accio-1688` 桥可用于任务需要的授权商品查询。用户选择原云端 ImageAgent 时才读取主技能的 `references/accio-cloud-contract.md`；普通生图失败不是改用其付费服务的授权。
- 保留已确认选择和真实任务引用。提交成功、收到任务号、返回文字、完成图片、完成商品应用是不同状态，只报告证据支持的结果。
- 生成图片不默认包含发布商品、替换线上主图或上传图片银行；用户已明确要求这些操作时沿用授权并核实实际回执。
- 不主动创建子 Agent、新线程或后台任务，本目录可由单个 Codex 会话使用。

## 文件与交付

需要保存时使用 `outputs/<任务名>/`，按需保存提示词、生成结果、最终图片和验收说明。保留原图，不覆盖已有文件，除非用户明确要求覆盖。文字咨询无需创建任务目录。

以中文交流，图中文字遵循用户语言并原样保留。预览本地图片使用绝对路径；提示词和联系表不能冒充独立图片。

`sources/` 是原文审计档案，不是运行技能，也不自动加载。其中有其他产品的路由和旧接口，仅在研究迁移差异时读取。

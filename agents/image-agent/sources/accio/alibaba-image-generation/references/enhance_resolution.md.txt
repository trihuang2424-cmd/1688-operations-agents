# 图片清晰度增强

## 功能说明

本 Skill 用于提升原图的清晰度，生成对应的高清图，适用于需要高分辨率图片的场景。

## 使用流程

### 1. 准备输入

- 输入：一张图片（支持常见格式：JPG、PNG、WEBP 等）
- 图片路径：用户提供的图片文件路径

### 2. 参数校验（前置拦截）

**在调用图像工具之前，必须先校验必传参数。如果参数为空，不发起请求，直接提示用户。**

| 必传参数 | 校验规则 | 缺失时处理 |
|---------|---------|-----------|
| `imageUrl` | 用户提供的图片 URL，不可为空 | 终止流程，提示"请提供需要增强清晰度的图片" |

### 3. 调用图像工具

清晰度增强使用 `image_edit` 工具的 `hd_upscale` task_type：

```
工具：image_edit
task_type：hd_upscale
参数：
  imageUrl: "<图片URL>"
```

**参数说明：**
- `imageUrl`：输入图片的 URL 地址
- 本场景**不需要构造 prompt**，工具会自动执行画质增强逻辑

**返回示例：**

工具直接返回处理后的图片 URL：

```json
{
  "imageUrl": "https://sc04.alicdn.com/kf/H696151c21a7342229edefd0b3769a579S/200042360/H696151c21a7342229edefd0b3769a579S.png"
}
```

### 4. 输出结果

**重要：获取到处理结果后，按照以下格式向用户展示，不要直接返回原始 JSON。**

**输出格式：**

```
已经帮你生成图片

![]({图片URL})
```

**输出示例：**

已经帮你生成图片

![](https://sc04.alicdn.com/kf/H696151c21a7342229edefd0b3769a579S/200042360/H696151c21a7342229edefd0b3769a579S.png)

- ✅ 正确：按上述格式输出，包含图片预览和创意工坊链接
- ❌ 错误：直接返回 JSON 或只返回图片 URL

## 注意事项

1. `hd_upscale` 为单一功能 task_type，**仅支持 1:1 比例**。若用户指定非 1:1 的 `aspect_ratio`，自动降级为 `simple_generation` 执行，prompt 使用"enhance resolution and sharpness"语义指令。
2. 当用户请求包含 ≥2 个意图（如"变清晰 + 换白底"）时，自动降级为 `simple_generation` 执行。
3. 本场景只做清晰度增强，严禁改变图片内容、构图、颜色或元素。
4. 若用户明确指定输出 1K/2K/4K 等分辨率，先判断当前 `image_edit` 是否支持 `resolution` 参数：
   - 支持 → 通过 `simple_generation` 的 `resolution` 参数指定目标分辨率。
   - 不支持 → 使用 `hd_upscale` 提升；4K 需求需先 `simple_generation` 生成 2K，再 `hd_upscale` 增强。
5. 处理失败时按 SKILL.md 中的错误处理规则执行。

## 使用示例

**场景：提升商品图片清晰度**

用户："帮我把这张图片变得更清晰"

执行步骤：
1. 获取用户提供的图片路径
2. 调用 `image_edit`，`task_type: hd_upscale`
3. 返回最终结果

**示例调用：**

```
工具：image_edit
task_type：hd_upscale
参数：
  imageUrl: "https://sc01.alicdn.com/kf/H5b56916614944dafaa06ea9f03aff8979.jpg"
```

**成功后输出示例：**

已经帮你生成图片

![](https://sc04.alicdn.com/kf/H696151c21a7342229edefd0b3769a579S/200042360/H696151c21a7342229edefd0b3769a579S.png)

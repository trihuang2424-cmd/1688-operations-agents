# SKU 换色功能

## 功能说明

本 Skill 用于将商品图片中的指定区域更换为指定颜色，适用于商品多颜色展示、SKU颜色变体生成等场景。

## 使用流程

### 1. 准备输入

- **原图**：需要换色的商品图片 URL
- **prompt**：描述换色区域（如：衣服的主体、包包的皮革部分、鞋子的鞋面等）
- **hexColor**：目标颜色的十六进制色值（如：#FF0000 表示红色，#0000FF 表示蓝色）
  - 如果用户输入的是颜色名称（如"红色"、"蓝色"），需要将其转换为对应的 hex 色值

### 2. 参数校验（前置拦截）

**在调用图像工具之前，必须先校验必传参数。如果参数为空，不发起请求，直接提示用户。**

| 必传参数 | 校验规则 | 缺失时处理 |
|---------|---------|-----------|
| `imageUrl` | 用户提供的图片 URL，不可为空 | 终止流程，提示"请提供需要换色的商品图片" |
| `hexColor` | 目标颜色的十六进制色值，不可为空 | 终止流程，提示"请提供目标颜色（如红色、#FF0000）" |

### 3. 调用图像工具

SKU 换色使用 `image_edit` 工具的 `simple_generation` 或 `complex_generation` task_type：

```
工具：image_edit
task_type：simple_generation 或 complex_generation
参数：
  imageUrl: "<图片URL>"
  prompt: "<换色描述 + 固定约束文案>"
```

**参数说明：**
- `imageUrl`：输入图片的 URL 地址
- `prompt`：换色 prompt，由"用户/Agent 换色描述"与固定约束文案拼接而成

**Prompt 构建：**

用户/Agent 生成部分示例：

```
Change the product color to navy blue
```

或中文描述：

```
将商品颜色改为酒红色
```

固定拼接文案：

```
严格保持其原有的款式、轮廓、纹理结构及光照效果不变。颜色替换需自然逼真，避免出现不协调的色偏或光影失真，同时完整保留图像中的所有非主体细节（如背景、配饰、材质反光等），确保整体视觉效果真实且一致。
```

完整 prompt 结构：

```
{用户/Agent 的换色描述 prompt} + 严格保持其原有的款式、轮廓、纹理结构及光照效果不变。颜色替换需自然逼真，避免出现不协调的色偏或光影失真，同时完整保留图像中的所有非主体细节（如背景、配饰、材质反光等），确保整体视觉效果真实且一致。
```

task_type 选择：
- 单色、单区域换色 → `simple_generation`
- 多区域、渐变、复杂纹理换色 → `complex_generation`

**返回示例：**

工具直接返回处理后的图片 URL：

```json
{
  "imageUrl": "https://sc04.alicdn.com/kf/H696151c21a7342229edefd0b3769a579S/200042360/H696151c21a7342229edefd0b3769a579S.png"
}
```

### 4. 输出结果

**重要：获取到处理结果后，按照以下格式向用户展示，不要直接返回原始 JSON。**

**输出格式：**

```
已经帮你生成图片

![]({图片URL})
```

**输出示例：**

已经帮你生成图片

![](https://sc04.alicdn.com/kf/H696151c21a7342229edefd0b3769a579S/200042360/H696151c21a7342229edefd0b3769a579S.png)

- ✅ 正确：按上述格式输出，包含图片预览和创意工坊链接
- ❌ 错误：直接返回 JSON 或只返回图片 URL

## 注意事项

1. **prompt 规范**：
   - 必须明确指定要换色的区域，如"商品主体"、"衣服的主体"、"包包的皮革部分"、"鞋子的鞋面"等
   - 如果用户没有指定换色区域，默认使用"商品主体"
2. **hexColor 规范**：
   - 必须是有效的十六进制色值格式，如"#FF0000"
   - 如果用户输入颜色名称，需先转换为对应的 hex 色值
   - 支持 3位简写（如"#F00"）和 6位完整格式（如"#FF0000"）
3. 款式、轮廓、纹理结构必须严格保持不变。
4. 光照效果需与原图一致，避免色偏或光影失真。
5. 背景、配饰、材质反光等非主体细节必须完整保留。
6. 处理失败时按 SKILL.md 中的错误处理规则执行。

## 使用示例

**场景：将红色衣服换成蓝色**

用户："帮我把这件红色衣服换成蓝色"

执行步骤：
1. 获取用户提供的原图 URL
2. 识别换色区域："衣服的主体"
3. 将颜色名称"蓝色"转换为 hex 色值："#0000FF"
4. 构建 prompt：`将商品颜色改为蓝色。严格保持其原有的款式、轮廓、纹理结构及光照效果不变。颜色替换需自然逼真，避免出现不协调的色偏或光影失真，同时完整保留图像中的所有非主体细节（如背景、配饰、材质反光等），确保整体视觉效果真实且一致。`
5. 调用 `image_edit`，`task_type: simple_generation`，传入原图与 prompt
6. 返回最终结果

**示例调用：**

```
工具：image_edit
task_type：simple_generation
参数：
  imageUrl: "https://sc01.alicdn.com/kf/H5b56916614944dafaa06ea9f03aff8979.jpg"
  prompt: "将商品颜色改为蓝色。严格保持其原有的款式、轮廓、纹理结构及光照效果不变。颜色替换需自然逼真，避免出现不协调的色偏或光影失真，同时完整保留图像中的所有非主体细节（如背景、配饰、材质反光等），确保整体视觉效果真实且一致。"
```

**成功后输出示例：**

已经帮你生成图片

![](https://sc04.alicdn.com/kf/H696151c21a7342229edefd0b3769a579S/200042360/H696151c21a7342229edefd0b3769a579S.png)

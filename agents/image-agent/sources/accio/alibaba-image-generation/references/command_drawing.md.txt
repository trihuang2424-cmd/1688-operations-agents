# 指令绘图

## 功能说明

本 Skill 用于根据用户的自然语言指令和参考图片，生成符合指令描述的新图像。作为图像生成能力的兜底方案，当用户的图像处理需求无法被其他专项能力覆盖时，通过本能力实现灵活的图像生成。

**执行判定条件**：当用户的需求不能命中以下任何图像相关 skill 时，执行此 skill：
- 背景消除 (remove-bg)
- 水印移除 (remove-watermark)
- 商品换色 (sku-color-change)
- Logo贴图 (apply-logo)
- 场景图生成 (product-scene-display)
- 细节生成 (generate-detail)
- 清晰度增强 (enhance-resolution)
- 模特图生成 (model-image)
- 图片翻译 (image-translation)

## 使用流程

### 1. 准备输入

- **用户指令**：描述期望生成图像的自然语言文本（如"把这张图片中的猫换成狗"、"给这个人物加上墨镜"、"将背景换成海滩"等）
- **参考图片**：用户提供的原始图片 URL 地址（可选；无参考图片时直接文字生图）

### 2. 参数校验（前置拦截）

**在调用图像工具之前，必须先校验必传参数。如果参数为空，不发起请求，直接提示用户。**

| 必传参数 | 校验规则 | 缺失时处理 |
|---------|---------|-----------|
| `prompt` | 用户的自然语言指令，不可为空 | 终止流程，提示"请描述您希望对图片进行的操作" |

> 注：`imageUrl` 为选填参数。用户未提供参考图片时，使用 `image_generate` 进行纯文字生图。

### 3. 调用图像工具

#### 3.1 有参考图片

若用户提供了参考图片，使用 `image_edit` 工具：

```
工具：image_edit
task_type：simple_generation 或 complex_generation
参数：
  imageUrl: "<参考图片URL>"
  prompt: "<用户指令>"
```

**参数说明：**
- `imageUrl`：输入参考图片的 URL 地址
- `prompt`：用户的自然语言指令，描述期望生成的图像效果
- `task_type` 选择：
  - 单区域、局部、简单编辑 → `simple_generation`
  - 多区域、全图变换、高保真要求 → `complex_generation`

#### 3.2 无参考图片

若用户未提供参考图片，使用 `image_generate` 工具：

```
工具：image_generate
task_type：simple 或 complex
参数：
  prompt: "<用户指令>"
```

**参数说明：**
- `prompt`：用户的自然语言指令
- `task_type` 选择：
  - 单主体、简单场景、低成本 → `simple`
  - 多元素、海报、模特、3D 风格、高细节 → `complex`

**返回示例：**

工具直接返回生成的图片 URL：

```json
{
  "imageUrl": "https://sc04.alicdn.com/kf/H696151c21a7342229edefd0b3769a579S/200042360/H696151c21a7342229edefd0b3769a579S.png"
}
```

### 4. 输出结果

**重要：获取到处理结果后，按照以下格式向用户展示，不要直接返回原始 JSON。**

**输出格式：**

```
已经帮你生成图片

![]({图片URL})
```

**输出示例：**

已经帮你生成图片

![](https://sc04.alicdn.com/kf/H696151c21a7342229edefd0b3769a579S/200042360/H696151c21a7342229edefd0b3769a579S.png)

- ✅ 正确：按上述格式输出，包含图片预览和创意工坊链接
- ❌ 错误：直接返回 JSON 或只返回图片 URL

## 注意事项

1. **执行判定**：仅在用户图像需求无法命中其他专项 skill 时执行。
2. 有参考图片时使用 `image_edit`，无参考图片时使用 `image_generate`。
3. 根据编辑/生成复杂度选择 `simple_generation` / `complex_generation` 或 `simple` / `complex`。
4. 处理失败时按 SKILL.md 中的错误处理规则执行。

## 使用示例

**场景：根据指令修改图像**

用户："帮我把这张图片里的红色汽车改成蓝色"

执行步骤：
1. 判断需求：用户要求"改颜色"，但此需求涉及自由指令而非标准 SKU 换色流程
2. 获取用户提供的图片 URL
3. 获取用户指令："帮我把图片里的红色汽车改成蓝色"
4. 调用 `image_edit`，`task_type: simple_generation`，传入原图与 prompt
5. 返回最终结果

**示例调用（有参考图片）：**

```
工具：image_edit
task_type：simple_generation
参数：
  imageUrl: "https://sc01.alicdn.com/kf/H5b56916614944dafaa06ea9f03aff8979.jpg"
  prompt: "帮我把图片里的红色汽车改成蓝色"
```

**示例调用（无参考图片）：**

```
工具：image_generate
task_type：simple
参数：
  prompt: "生成一张红色跑车在海边公路行驶的图片"
```

**成功后输出示例：**

已经帮你生成图片

![](https://sc04.alicdn.com/kf/H696151c21a7342229edefd0b3769a579S/200042360/H696151c21a7342229edefd0b3769a579S.png)

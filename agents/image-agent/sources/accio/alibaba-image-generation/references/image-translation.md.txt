# 图片翻译功能

## 功能说明

本 Skill 用于识别图片中的文本内容，并将其翻译为指定的目标语言，生成翻译后的图片。适用于商品图翻译、海报翻译、文档图片翻译等场景。

## 使用流程

### 1. 准备输入

- **imageUrl**（必填）：需要翻译的图片 URL 地址
- **目标语言**：目标语言代码或语言名称（如 `vi` 或"越南语"）

**支持的语言映射表：**

| 语言代码 | 语言名称 |
|---------|---------|
| de | 德语 |
| es | 西班牙语 |
| fr | 法语 |
| it | 意大利语 |
| pt | 葡萄牙语 |
| ru | 俄语 |
| ja | 日语 |
| ko | 韩语 |
| en | 英语 |
| zh | 中文 |
| vi | 越南语 |
| th | 泰语 |
| ms | 马来语 |
| ar | 阿拉伯语 |
| id | 印尼语 |

**语言输入处理逻辑：**
1. 接收用户输入的语言（可以是语言代码如 `vi`，也可以是语言名称如"越南语"）
2. 根据映射表将语言名称转换为对应的语言代码/语言名称
3. 将目标语言嵌入 prompt 中调用图像工具

### 2. 参数校验（前置拦截）

**在调用图像工具之前，必须先校验必传参数。如果参数为空，不发起请求，直接提示用户。**

| 必传参数 | 校验规则 | 缺失时处理 |
|---------|---------|-----------|
| `imageUrl` | 用户提供的图片 URL，不可为空 | 终止流程，提示"请提供需要翻译的图片" |
| 目标语言 | 目标语言代码或名称，不可为空且需在支持列表中 | 终止流程，提示"请提供目标翻译语言（如英语、vi）" |

### 3. 调用图像工具

图片翻译使用 `image_edit` 工具的 `simple_generation` task_type：

```
工具：image_edit
task_type：simple_generation
参数：
  imageUrl: "<图片URL>"
  prompt: "<翻译 prompt>"
```

**参数说明：**
- `imageUrl`：需要翻译的图片 URL 地址
- `prompt`：翻译 prompt，将 `<target_lang>` 替换为目标语言名称（如 English、日本語、한국어 等）

**Prompt 模板：**

```
将提供的图片中可见的文本全部翻译成<target_lang>，并将原文全部替换为译文。最终效果必须与原图完全一致，无法区分。
必须严格遵守
## 字体匹配：
- 完全复制原文的字体、字重、大小、颜色和字距。
- 完美匹配应用于原文字符的任何透视变形、曲率或扭曲效果。
## 背景完整性：
- 保留原始图片背景，不得进行任何更改。
- 不得改变产品或场景的形状、结构或构图。
## 无缝融合：
- 确保新文本与背景自然融合。无可见边缘、切割痕迹或色块差异。
- 模拟逼真的光影效果：新文本必须投射/接收与场景光源一致的阴影。
## 内容准确性：
- 译文必须语法正确且符合上下文语境。
- 请勿修改目标区域以外的任何文本。
- 不得出现乱码、拼写错误或错别字。
```

> **强制规则**：图片翻译场景必须调用 `image_edit` 输出一张翻译后的图片，严禁仅以文本形式输出翻译结果，严禁跳过工具调用直接回复译文。

**返回示例：**

工具直接返回处理后的图片 URL：

```json
{
  "imageUrl": "https://sc04.alicdn.com/kf/H696151c21a7342229edefd0b3769a579S/200042360/H696151c21a7342229edefd0b3769a579S.png"
}
```

### 4. 输出结果

**重要：获取到处理结果后，按照以下格式向用户展示，不要直接返回原始 JSON。**

**输出格式：**

```
已经帮你生成图片

![]({图片URL})
```

**输出示例：**

已经帮你生成图片

![](https://sc04.alicdn.com/kf/H696151c21a7342229edefd0b3769a579S/200042360/H696151c21a7342229edefd0b3769a579S.png)

- ✅ 正确：按上述格式输出，包含图片预览和创意工坊链接
- ❌ 错误：直接返回 JSON 或只返回图片 URL

## 语言映射处理

**支持用户输入语言代码或语言名称。**

系统会自动识别用户输入并进行转换：
- 如果用户输入语言代码（如 `vi`），直接使用对应语言名称嵌入 prompt
- 如果用户输入语言名称（如"越南语"），根据映射表转换为语言代码后，再取对应语言名称嵌入 prompt

**语言映射表（代码 ↔ 名称）：**

```python
lang_code = {
    'de': '德语',
    'es': '西班牙语',
    'fr': '法语',
    'it': '意大利语',
    'pt': '葡萄牙语',
    'ru': '俄语',
    'ja': '日语',
    'ko': '韩语',
    'en': '英语',
    'zh': '中文',
    'vi': '越南语',
    'th': '泰语',
    'ms': '马来语',
    'ar': '阿拉伯语',
    'id': '印尼语'
}
```

**转换逻辑：**
1. 检查用户输入是否在 `lang_code.keys()` 中（语言代码）→ 取对应语言名称嵌入 prompt
2. 检查用户输入是否在 `lang_code.values()` 中（语言名称）→ 直接使用
3. 如果都不匹配 → 返回语言映射表提示用户

## 注意事项

1. **输出必须且只能是翻译后的图片，严禁输出翻译文本**。
2. 必须由用户指定目标语言。
3. 字体、字重、大小、颜色、字距需与原文完全匹配。
4. 背景不得有任何改变。
5. 光影效果需与场景一致。
6. 译文需语法正确且符合上下文语境。
7. 不得修改目标区域以外的文本。
8. 处理失败时按 SKILL.md 中的错误处理规则执行。

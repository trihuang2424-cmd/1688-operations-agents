# Codex 图片执行适配

替换原Accio工具合同，设计方法与执行后端分离，不搬用原参数、任务号或计费假设。

## 后端

1. 遵循用户明确选定的服务/模型，检查当前会话的真实能力。无法满足时说明，不默默换服务。
2. 普通生图默认读取当前安装的 `imagegen` 技能并使用其内置路径。本机入口：`/Users/shileqi/.codex/skills/.system/imagegen/SKILL.md`；移机后从技能目录重新定位。
3. 内置路径无需用户另配API密钥，是否可用由会话工具决定。CLI/API仅在用户明确选择或确认后使用，遵循imagegen的模型、凭据与脚本规则。
4. 工具不可用时完成商品分析、完整提示词和任务记录，说明后端缺失及替代路径。只在用户选择后使用替代路径，不能把“已安装”说成“已验证可出图”。
5. Accio图片/视频工具不是默认替代服务；选择原云端时读 [accio-cloud-contract.md](accio-cloud-contract.md)。

## 输入与参数

- 确定新创作或继承/编辑现有商品。需要保持商品身份时，确保参考图进入真实工具输入，而非仅在文字中说“参考原图”。
- 内置工具编辑本地图片时，先用 `view_image` 将其放入上下文，再按当前imagegen合同调用；文件路径不自动成为图片参数。
- 远端工具若要求URL或资产ID，使用其支持的素材渠道和真实返回值，不伪造地址。仅在选定服务需要时上传必要素材。
- 读取实时schema并在同一任务复用。Accio的 `task_type`、`auto_generation`、`simple_generation`、`complex_generation` 和 `resolution` 不是Codex通用参数。
- 像素、透明背景、蒙版、模型控制按所选路径核实。2K只是可选质量目标；放大不能冒充新增真实细节。
- 不同用途使用不同提示词和引用，一个提示词的多候选不等于套图。并发只用宿主已支持机制，不创建额外子Agent或模型会话。

## 结果

保存真实产物并按请求复制到任务目录，保留原图和版本。本地交付无需上传。内置路径遵循imagegen的保存规则，不假设生成接口有目的路径参数。

任务号是已提交，文字是文字结果，可访问且检查过的图像才是图片交付。分别验证商品保持、中文、事实、数量、尺寸。超时先核实状态，不盲目重复付费提交。

读文件、写提示词和本地结构检查不调用Accio生图。真实模型服务按自身额度/计费运行，不宣称免费或绕过计费，不套用另一服务的价格。

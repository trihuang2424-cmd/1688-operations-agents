# Codex 图片工作流

接手运营、营销或产品任务时复用目的、数量/顺序、图片角色、证据、精确文案、尺寸、语言、风格和真实依赖。静态图片任务不重做完整商业分析或生成视频。

一张图直接完成，多图按 [parallel-generation.md](parallel-generation.md) 准备完整提示词。共享商品图或风格文字不等于前后依赖；真正使用前张产物的编辑才等待。

缺失信息影响正确性时用当前提问能力补齐。已授权生成不追加例行确认；提示词请求止于预览。不要使用Accio的 `ask_user` 参数、界面组件或 `<follow>` 语法。

关联请求与结果，区分计划、提交、可用、检查、交付、失败、未知状态。后续只修改相关输出，保留已接受结果。任务号来自真实调用，未知状态不盲目重发。

按原顺序交付实际图片，以绝对本地路径或原生媒体呈现。项目图片保存在工作目录，部分成功逐项说明，不用联系表、文字或不可访问文件冒充成图。商品应用/发布按其实际授权与回执处理。

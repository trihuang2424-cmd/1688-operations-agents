## 商品资料

优先用现有资料。需要授权店铺数据且有 `accio-1688` 桥时，先检查连接状态，再搜索/描述相关商品查询工具，按实时schema调用。复用已确认授权和商品选择。不要猜店铺、复用其他会话ID或复制网关凭据。

保留事实来源和商品ID，避免查询与图片任务无关的客户、订单资料。图片银行写入、上传、商品更新不属于查询。连接缺失时用现有材料继续，列出真正影响正确性的缺口。

## 真实性

视觉表达与商品事实分开。照明、取景、背景可合理设计；认证、承重、寿命、产能、材质、MOQ与交期需有依据。概念款不能冒充在售SKU，工厂创意图不能证明真实设施。

中文文案保留字形、单位与限定条件，密集规格表可用确定性排版。平台上传规则需核实当前类目与图片位，并记录来源；未核实时只给设计建议，不声称通过平台审核。

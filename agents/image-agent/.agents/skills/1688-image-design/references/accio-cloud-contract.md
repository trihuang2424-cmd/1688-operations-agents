# 原Accio云端图片Agent：可选兼容说明

仅用于用户明确选择原云端服务或检查协议。此文不是可执行客户端，也未把原服务安装进Codex。

| 入口 | 已知合同 | 限制 |
|---|---|---|
| 原生 `image_agent_run` | Host处理授权、受信素材、规约读取凭据、交互/续接；支持文字创作、基于图片、店铺选品、仅提示词等模式 | 普通MCP桥不能假设存在，更不能伪造Host上下文/凭据 |
| MCP `image_agent` | 已观察到会话、问题、checkpoint、图片、店铺、resume等字段，以实时描述为准 | 尚未验证与原生入口的后端和设计能力完全一致 |

协议咨询只搜索/描述工具，不提交生成。执行前核实实时schema、真实授权及上下文取得方式。若没有有效session/checkpoint来源，不能用随机ID冒充。

原生规约要求 `instruction` 只转述用户目标，具体设计由云端完成；本地路径则由Codex展开完整提示词。两者不机械混用，不把原生输入模式塞入普通MCP参数。

原生路径观察到额度拒绝与成本字段，但MCP图片调用的收费账户、价格、套餐仍未验证。仅提示词模式也不能假定免费；复用授权不代表免费生图。

真实调用后区分文字、图片产物、待交互、失败和商品应用回执。未接入widgets/resume不能以普通JSON响应冒充完成。超时或本地取消不能证明云端执行或计费停止。

# 套图场景模板

迁移商品定招生图的表达方法，移除私有云端默认扩写、强制英文、固定1:1、75%–80%占比和固定3–6工序等限定。

每张图写完整提示词，不能省略prompt等待不存在的云端补齐。共享商品身份和具体风格约束，按用途变化构图，无需固定先生成锚图。

## 场景图

明确真实使用环境、载体、支撑和接触关系，补足合理阴影、透视与光照。不能用参考物夸大尺寸，不能借换背景重建未知结构。

句式：把参考商品放在【具体场景】的【合理支撑物】上，让【真实用途/关系】可见。保留【已核实外形和属性】，使阴影、透视和光照一致，不增加未经要求的配件。

## 细节图

只突出真实可见部位、纹理和工艺，必要时关联整体位置。不从放大推断内部结构，不强制无字或英文。

句式：展示【可见部位】的细节，将其关联到【整体位置】，用【适当光线】呈现【有依据的纹理/接缝】，保留【商品身份】。

## 卖点图

从用户或商品资料确定主卖点和支撑事实，安排文字层级与留白。参数、认证、定制承诺可溯源。促销文案需有用户要求和真实条款。

句式：用【动作/细节】说明【真实卖点】。主标题逐字为“【原文】”，支撑文字为“【原文】”，位于【留白区域】，不遮挡【证据部位】。

## 模特图

分开商品、人物与姿态/风格参考，保持真实穿戴、受力、遮挡和垂坠。不能改变商品颜色、结构和图案。用户要求换背景或裁切时，不套来源模板的固定背景、完整头部等限制。

## 工序与实力图

取得实际工序、顺序、名称与证据，不能凭类目推断卖家生产线。概念示意须标明。阶段数取自真实步骤，编号唯一，箭头匹配实际顺序；真实分支不能为套模板而删除。

句式：依据【N个已确认阶段】制作流程图：【逐项原文】。每个编号对应阶段、说明和示意，保留【真实顺序/分支】。图中文字为【指定语言原文】，不增造机器、资质或产能。

通过 [generation-runtime.md](generation-runtime.md) 执行，保留各图用途与文件，不强制每次生成所有类型。

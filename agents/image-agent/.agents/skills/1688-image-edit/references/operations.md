# 编辑操作与提示词

选当前操作即可，以下是文字约束，不是工具参数。实际调用统一遵循主设计技能的Codex适配。

| 操作 | 输入与表达 | 验收 |
|---|---|---|
| 白底/透明背景 | 原图；明确纯白或真实透明，保留商品边缘、孔洞与必要阴影 | 商品无残边/缺损；透明检查alpha，不能把棋盘格当透明 |
| 换背景/场景 | 原图与目标环境；改变周围场景，必要时协调接地阴影，不修改产品 | 主体、支撑、比例、光照合理；未知遮挡结构未被编造 |
| SKU换色 | 原图、准确目标色/色样、修改区域；保留结构、纹理与其他区域 | 多SKU名称/颜色对应，不把新概念色称为已有库存 |
| Logo应用 | 商品图与实际Logo原件；明确物体表面或画布位置、工艺效果 | 拼写/比例准确，标记不重复，位置与透视属于正确坐标系 |
| 模特/试穿 | 商品图；有指定人物时加真实参考；姿态服从商品展示 | 产品图案、结构、穿戴接触、比例、遮挡准确 |
| 细节特写 | 可见且有依据的局部；必要时使用真实裁切或额外照片 | 细节可回溯到原物，不能从模糊图恢复虚构结构 |
| 清晰度 | 原图和所需交付尺寸；先判断缩放、降噪、压缩或失焦问题 | 不声称放大恢复真实丢失信息，检查伪纹理与字形 |
| 文字替换/移除 | 指定文字区域、逐字替换内容、保留项 | 检查字形、数字、单位及其他原文字 |
| 翻译 | 源图、目标语言、区域映射；保留需保持的商品标签 | 语义、限定词、排版与产品身份正确 |
| 水印/角标清理 | 用户指定的目标区域；保持商品固有标记和未指定内容 | 无残影/重复Logo，未擅自删除其他产品信息 |
| 其他明确编辑 | 从实际图像确定目标、保留属性与连带变化 | 按同一规范比对，不机械归入专有task_type |

## 可组合句式

白底：“将商品以外的背景改为纯白，保留真实商品外形、颜色、纹理、可见文字及细小孔洞。保持自然接触阴影，不添加标记。”透明目标则改写背景要求，并核实后端支持。

场景：“把参考商品置于【指定场景】的【支撑物】上。保持【已知商品身份】，允许匹配新场景的合理光影变化；不推测隐藏部位，不改变商品尺寸含义。”

换色：“仅将【明确部位】的颜色改为【目标色】。保留原材质的纹理、反光和结构，其他部位及已有文字保持。参考图二仅作为颜色来源。”

Logo：“图一为商品，图二为Logo原件。将图二以【工艺/平面角标】呈现在【明确位置】，准确保留标记字形、比例和数量。”表面效果随表面透视；画布角标保持平面、相对位置及比例，不贴到物体上。

模特：“保持参考商品的【真实结构、颜色、图案】，由【已指定人物/模特描述】在【姿态】中展示，使【关键部位】可见。维持合理穿戴、受力、遮挡与接触。”背景、裁切、人物类型遵循用户要求，不强制完整头部或固定旧背景。

细节：“展示原图中【真实可见区域】的近景，突出【有证据的纹理/接缝】，保留其与商品的对应关系。不要添加无法确认的涂层、内部零件或工艺。”

文字：“仅将【区域/原文】替换为逐字文案‘【目标文本】’，保留【其他文字和产品】，调整必要的行距/字号以避免遮挡。”严格像素保持场景优先可用的确定性排版，不承诺生成模型必然原样保存。

用户明确要求多个改动时可以合并，但检查保留项不要阻止这些改变。单项错误修复不要顺带换风格或重做整图。

# 图片诊断与优化

原AI图片工作室的“一键优化”会把图片交给专有后端，内部诊断/打分未取得。此处用Codex可解释的检查代替该封闭调用，不声称使用相同模型或分数。

根据真实图片检查：主体辨识、边缘与背景、曝光/偏色、清晰度、透视/接触、文案可读性、商品事实和请求的发布尺寸。只报告实际观察到的问题；平台合规结论需有当前目标类目规则。

选择最影响本任务的缺陷，再确定解决方式：裁切/缩放/压缩可用确定性处理；局部文字可考虑排版覆盖；背景、场景或复杂视觉修复按当前图片后端。无须每次调用生成模型。

用户只问诊断时交付问题与建议。用户要求优化时，在其范围内修复，不改变SKU、添加新卖点或编造认证。按同一指标比较前后图，记录未解决项。一次针对性修正失败后说明限制，除非用户已授权继续迭代。

模糊原图的推测细节必须说明不确定性；放大不等于真实细节恢复。工具返回成功不等于肉眼质量合格。
